# StreamChat Overlay
## A Vibecode Project

A real-time chat overlay for **TikTok Live** and **YouTube Live**, built for OBS and desktop use. The app is now packaged as a **Tauri v2 desktop shell** with a local **Node.js + Express** backend that serves the overlay web UI on `http://127.0.0.1:5000`.

## Features

- Live chat overlays for **TikTok** and **YouTube** streams
- Public stream support with no login required
- Transparent floating overlay window for OBS or standalone desktop use
- Smooth chat rendering with automatic reconnect handling
- **TikTok**: chat, gifts, follows, joins, likes, and live viewer counts
- **YouTube**: live chat and Super Chats with a clean chat-only layout
- Desktop shortcuts for lock/unlock and quick interaction toggles

## Run locally

```bash
git clone https://github.com/Asmodeus7999/StreamChatOverlay.git
cd StreamChatOverlay
npm install
npm run dev
```

This launches the Tauri desktop app in development mode. The app starts the local backend automatically and opens the overlay at `http://127.0.0.1:5000`.

## Build the desktop app

```bash
npm run dist
```

This prepares the bundled backend and runs the Tauri build for the desktop application. The compiled output is generated by the Tauri project under the app bundle folders.

## Use in OBS

1. Add a **Browser Source** to your scene in OBS.
2. Point it to `http://127.0.0.1:5000`.
3. Set the width and height to match your layout (for example `400x800`).
4. Select **TikTok** or **YouTube**, enter your stream details, and connect.
5. The setup panel fades out and the live chat remains visible.

**TikTok**: enter your `@username`.

**YouTube**: paste the full stream URL.

## Controls

The overlay starts in an **unlocked** state so you can move and resize it.

- `Ctrl+Alt+L` — toggle lock mode; locked mode makes the overlay click-through and hides the drag bar/border.
- `Ctrl+Alt+I` — temporarily re-enable interaction while still locked.
- Right-click — open a quick menu with **Refresh** and **Toggle DevTools** when unlocked or temporarily interactive.

## Project layout

- `public/` — web frontend assets
- `src-tauri-app/` — Tauri v2 desktop shell and native runtime setup
